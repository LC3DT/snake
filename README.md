## 🎮 游戏项目：霓虹幻影 · 经典贪吃蛇重制版 (Neon Snake: Remastered)

### 📌 项目概述
本项目是一款基于纯粹前端技术（HTML5 Canvas + Vanilla JavaScript）从零构建的现代化轻量级网页游戏。它不仅完美复刻了经典街机游戏“贪吃蛇”的核心灵魂，更在视觉美学、操作手感和底层代码架构上进行了全面现代化的重塑。游戏无需任何安装或环境配置，点开即玩，旨在提供极致流畅、极简且纯粹的休闲体验。

### 🎨 视觉与交互体验 (UI/UX)
游戏摒弃了早期粗糙的像素块，采用了充满未来感的**暗黑霓虹 (Dark Neon)** 艺术风格：
*   **赛博朋克配色：** 游戏以深邃的暗灰色调为背景，辅以隐约的暗纹网格（Matrix Grid），营造出数字空间的氛围。
*   **荧光实体：** 蛇身采用高饱和度的“赛博绿”发光材质，在移动时带有轻微的荧光拖尾效果；食物则是高亮的“警示红”能量块，具有呼吸灯般的闪烁动画，极具视觉冲击力。
*   **极简交互界面：** 界面没有任何冗余元素。顶部悬浮着科技感字体的“当前得分”与“历史最高分”看板。游戏开始和结束的弹窗采用了平滑的毛玻璃半透明效果 (Glassmorphism)，确保玩家的注意力始终聚焦在游戏本身。

### 🕹️ 核心玩法与机制
*   **经典网格法则：** 游戏在一个严格划分的二维网格系统中运行。玩家通过 `W/A/S/D` 或 `方向键` 操控能量蛇在网格中穿梭，吞噬随机生成的红色能量块。
*   **成长与挑战：** 每吞噬一个能量块，蛇身便会延长一节，同时获得 10 点积分。随着蛇身的不断延长，游戏空间会被逐渐压缩，对玩家的路线规划和反应速度提出越来越高的挑战。
*   **严格的生存法则：** 游戏遵循残酷的即死机制。一旦蛇头触碰到四周的物理边界（撞墙），或者发生逻辑错误首尾相连（咬到自己），系统将立即判定游戏结束 (Game Over)。
*   **人性化防误触：** 游戏内置了智能输入拦截系统，杜绝了反人类的“瞬间掉头”操作。例如，当蛇正在向右疾驰时，按下左方向键将被系统无视，有效避免了玩家因手误导致的冤枉死亡。

### ⚙️ 特色进阶功能
*   **本地最高分记忆：** 游戏接入了浏览器的 `localStorage` API。即便玩家关闭浏览器并重新打开，曾经创下的“最高得分”依然会傲然悬挂在榜首，时刻激发玩家的挑战欲。
*   **战术暂停系统：** 战斗中随时可以通过按下 `P` 键或 `Esc` 键切入暂停状态。屏幕会罩上一层阴影并显示暂停提示，再次按下即可无缝恢复战斗，满足玩家随时应对突发事件的需求。

### 💻 技术架构与性能亮点 (写给开发者的彩蛋)
作为一款追求极致的 Web 游戏，本项目在工程实现上同样精雕细琢：
*   **零依赖与极致轻量：** 不使用任何诸如 React、Vue 或 Phaser 等重型框架或游戏引擎。全部逻辑依赖原生 DOM API 与原生 JS 实现，加载速度达毫秒级。
*   **高性能渲染：** 抛弃了传统的 DOM 节点堆叠法，全面采用 HTML5 `<canvas>` API 进行 2D 绘图渲染。结合 `requestAnimationFrame` 驱动的游戏主循环，确保游戏始终在浏览器原生最高帧率（通常为 60FPS）下丝滑运行，告别任何卡顿与掉帧。
*   **面向对象 (OOP) 架构：** 核心逻辑 `game.js` 被优雅地拆分为 `Game`（状态控制）、`Snake`（实体行为）、`Food`（资源生成）和 `Input`（事件监听）等多个独立的类，代码结构清晰、高内聚低耦合，极具扩展性。
